Issue #5501 (FR: Apple Pencil Pro support) implemented 2026-08-05, MERGED as PR #5511
the same day (worktree and branch cleaned up post-merge).
Design + plan in `.agents/plans/2026-08-05-apple-pencil-page-turner-{design,plan}.md`.

Approach: pencil gestures = two new native keys (`PencilDoubleTap`, `PencilSqueeze`)
through the existing hardware page-turner pipeline; bound via the existing "Set key"
learn mode with zero new settings UI (only the iOS description text changed).

Non-obvious learnings:

- **`UIPencilInteraction.preferredTapAction` / `.preferredSqueezeAction` are CLASS
  properties, not instance properties** — `interaction.preferredTapAction` is a
  compile error ("static member cannot be used on instance"). Verified against the
  UIKit SDK header; `preferredSqueezeAction` is `API_AVAILABLE(ios(17.5))` and both
  return `UIPencilPreferredAction` (respect only `.ignore`). Squeeze delegate fires
  per phase; forward on `.ended` only.
- **Pencil bindings must NOT acquire media-key interception**: `usePagination` now
  splits `hasMediaKeyBinding` (native minus pencil → `acquirePageTurnerKeyInterception`)
  from `hasNativeBinding` (any native → listener + new `deviceStore.ensureKeyForwarding()`,
  which installs `window.onNativeKeyDown` without `interceptKeys`). Acquiring for
  pencil-only would claim MPRemoteCommandCenter next/prev-track (Now Playing, #4691).
  The effect dep array changed from per-slot `source` fields to `[hardwarePageTurner]`
  object identity because the decision now depends on binding *ids*.
- The `UIPencilInteraction` is attached unconditionally in plugin `load()` — it is
  passive (no resource claims, never fires on iPhone), unlike `MediaKeyHandler`.
- **Swift compile check in a fresh worktree**: `swift build --triple
  arm64-apple-ios15.0-simulator --sdk $(xcrun --sdk iphonesimulator --show-sdk-path)`
  works in the plugin `ios/` dir but needs `.tauri/tauri-api` copied from the main
  checkout (gitignored, generated by tauri CLI; worktree:new does not create it).
- **iOS Simulator cannot emulate pencil double tap/squeeze** — device verification
  on iPad + Pencil Pro is PENDING after merge.
- Learn mode captured the new keys with no changes: `setKeyLearnMode` installs the
  forwarding handler and `PageTurnerSettings` accepts any keyName outside its
  Back/VolumeUp/VolumeDown exclusion list.
