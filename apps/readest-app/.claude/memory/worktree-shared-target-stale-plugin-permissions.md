Symptom (seen 2026-09-28 building PR #6429 with `pnpm dev-android` in `readest-pr-6429`):
`proc macro panicked ... generate_context!() ... failed to resolve ACL: SetPermissionNotFound { permission: "allow-update-reading-widget", set: "default" }`.

Cause: worktrees symlink `target` to the main checkout's `/Users/chrox/dev/readest/target`, so
cargo reuses a cached `tauri-plugin-native-bridge` build-script run and never regenerates the
gitignored `permissions/autogenerated/commands/*.toml` inside the new worktree. A command that
`permissions/default.toml` references (here `update_reading_widget`) then has no generated file.

Fix: `touch src-tauri/plugins/tauri-plugin-native-bridge/build.rs` and rebuild — the build
script reruns and writes the missing toml. Not a PR bug; don't report it as one.
